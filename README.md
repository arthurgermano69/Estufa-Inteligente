# Estufa Inteligente 

Sistema IoT para monitoramento e controle de temperatura e umidade utilizando ESP32, sensor BME680 e integração com Telegram.

## Funcionalidades

- Monitoramento de temperatura e umidade
- Controle automático do ar-condicionado
- Comandos via Telegram
- Monitoramento em tempo real

## Tecnologias utilizadas

- ESP32
- BME680
- Arduino IDE
- Telegram Bot API
- C/C++

## Projeto

O sistema realiza a leitura dos sensores e ativa automaticamente o sistema de refrigeração através de um relay quando necessário.
